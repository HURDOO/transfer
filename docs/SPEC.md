# 제품 명세

상태: 첫 MVP 수직 흐름 구현 완료

## 목표와 사용자

`옮기기`는 제3자 파일 전송 서비스 없이 자신이 운영하는 서버에서 파일 묶음이나 텍스트를 공유하고, 6자리 코드·링크·QR로 다시 수령하는 웹 서비스다. 주 사용자는 운영자 한 명이지만, 수령 링크와 API는 코드 소지자에게 공개된다.

## 핵심 사용 흐름

1. 보내는 사람이 파일을 하나 이상 고르거나 텍스트를 입력하고 만료 기한을 선택한다.
2. 서버가 내용을 영속 저장하고 선행 0을 허용하는 6자리 숫자 코드와 공유 링크를 만든다.
3. 화면은 코드, 복사 가능한 링크, 링크를 담은 QR을 보여준다.
4. 받는 사람은 홈에서 코드를 입력하거나 링크·QR로 수령 화면을 열어 텍스트를 복사하고 파일을 개별 다운로드한다.
5. 만료된 공유는 메타데이터 조회와 파일 다운로드 모두 즉시 거부된다.

## 기능 요구사항

- 한 공유에 파일 여러 개와 텍스트를 함께 담을 수 있다. 둘 중 하나는 반드시 있어야 한다.
- 만료 기한은 `1시간`, `1일`, `3일`, `1주일`, `30일`, `만료 안 함` 중에서 고른다. 기본값은 1일이다.
- 공유 코드는 정확히 6자리 숫자이며 활성 공유 사이에서 유일하다.
- 웹과 API는 같은 생성·조회·다운로드 계약을 사용한다.
- 업로드 한 번의 파일과 텍스트 합계는 최대 1 GiB다. 파일은 최대 50개, 텍스트는 최대 1 MiB다.
- 원래 파일명은 UTF-8 기준 512바이트까지 표시와 다운로드명으로 보존하되 저장 경로에는 서버가 만든 식별자만 사용한다. 경로 구분자와 제어 문자는 제거한다.
- 저장된 공유는 서버를 재시작해도 유지된다.

## 비기능 요구사항

- 파일 본문을 메모리에 모으지 않고 디스크로 스트리밍한다.
- 만료 여부는 정리 작업과 무관하게 매 조회·다운로드 시 서버 시각으로 판정한다.
- 파일은 `attachment`, `application/octet-stream`, `nosniff`로 내려 인라인 실행을 막는다.
- 코드 조회와 생성 API에 요청 제한을 두고, 로그에 텍스트·파일 내용은 남기지 않는다.
- 라이트·다크 테마, 모바일 320px, 키보드 조작, 명확한 포커스, 상태 알림을 지원한다.
- QR만으로 정보를 전달하지 않으며 코드와 링크를 항상 함께 제공한다.
- `prefers-reduced-motion`에서는 전송 완료 애니메이션을 축소한다.
- 업로드 요청 전체는 30분 안에 끝나야 한다. 멈춘 요청은 `408`로 종료하고 임시 데이터를 제거한다.

## API 계약

### `POST /api/shares`

`multipart/form-data` 요청을 받는다.

- `expiresIn`: `1h | 1d | 3d | 7d | 30d | never`, 필수
- `text`: 선택, UTF-8 최대 1 MiB
- `files`: 선택, 반복 가능한 파일 필드

성공 시 `201`과 코드, 절대 공유 URL, 생성·만료 시각, 선택 텍스트 본문, 파일 메타데이터를 반환한다.

### `GET /api/shares/:code`

텍스트와 파일 다운로드 URL을 포함한 수령 메타데이터를 반환한다.

### `GET /api/shares/:code/files/:fileId`

원래 이름을 사용해 파일을 스트리밍 다운로드한다.

### 오류

- 빈 공유, 잘못된 만료값·코드·multipart·파일명: `400`
- 총 업로드 제한 초과: `413`
- 업로드 시간 초과: `408`
- 요청 제한 초과: `429`
- 존재하지 않거나 만료된 공유·파일: 정보 노출을 줄이기 위해 `404`
- 코드 공간 예약 실패: `503`
- 예상하지 못한 저장 오류: 내용이 없는 일반화된 `500`

오류 응답은 `{ "error": { "code": string, "message": string } }` 형식이다.

## 범위 제외

- P2P 및 종단간 암호화
- 공유 비밀번호
- 여러 파일 ZIP 다운로드
- 사용자 계정과 관리 화면
- 공개 배포, TLS, 리버스 프록시
- Docker 이미지와 Raspberry Pi 운영 자동화

## 완료 조건

- 작은 텍스트와 파일 2개를 한 번에 공유하면 코드·링크·QR이 표시된다.
- 코드 입력과 직접 링크 모두 같은 수령 화면을 열고, 텍스트 복사와 두 파일 다운로드가 가능하다.
- 직접 API 호출로 생성→조회→다운로드가 동작한다.
- 빈 입력, 잘못된 코드, 합산 크기 제한, 만료, 재시작 영속성에 집중된 테스트가 있다.
- format, lint, typecheck, test, build가 통과한다.
- 데스크톱·모바일, 라이트·다크, 오류·빈 상태를 실제 브라우저에서 확인한다.

## 명시된 요구사항과 가정

명시된 요구사항은 여러 파일/텍스트 공유, 6자리 코드와 링크·QR, 여섯 만료 선택지, 웹과 API, 요청당 1GB 제한, 라이트·다크 화면, 로컬 개발과 향후 Raspberry Pi Docker 운영이다.

다음은 이번 구현의 합리적 가정이다.

- `1GB`는 파일 하나가 아니라 공유 요청 전체의 최대 크기이며 이진 단위인 1 GiB로 해석한다.
- `1달`은 30일이며 만료 기준은 서버 시각이다.
- `만료 안 함`은 운영자가 데이터를 지우기 전까지 유지한다.
- QR은 별도 저장 데이터가 아니라 공유 URL의 표현이다.
- 익명 생성·수령은 임시 MVP 제약이 아니라 제품 동작이다. 사용자 계정과 업로드 로그인은 범위에 넣지 않는다.

## 후속 배포 시스템에서 다룰 사항

- Docker와 공개 배포는 현재 범위에서 제외한다. 익명 업로드·다운로드는 유지하되, 공개 인터넷 배포 시에는 디스크 quota, 동시 요청 제한, TLS, 관측, 신고·차단 등 악용 대응을 별도 배포 시스템에서 마련한다. 6자리 코드는 수령 편의 코드이지 비밀키가 아니다.
